# netplay

Hidden until NextUI has netplay: stock minarch has none, so its `plugin.txt` has `requires=minarch-netplay`, and the loader leaves it off and logs why, so it never binds **Y**. Its name on the Plugins page says it needs NextUI netplay. Once it can load, **Y** on a game opens Host a game or Join a game. Joining asks for the host's name or IPv4 address on the keyboard, with `:port` for a port other than the `port` setting (55435 by default), and offers the last address next time. The game then launches through its emulator pak's `launch.sh` with `--host --port <port>` or `--connect <address> --port <port>` before the game's path, each part single-quoted. Those arguments, and a `launch.sh` that passes what comes before the game to minarch, are assumptions to confirm once minarch has netplay. A game without an emulator pak is cancelled rather than launched without netplay. Only launches picked with Host or Join are replaced. With another plugin that replaces launches, such as `emulator-override`, only the first of them in load order replaces a launch: when that's the other plugin, netplay's `replace_launch` is refused, so netplay cancels the launch and says so rather than letting it start without netplay; when it's `netplay`, the netplay launch uses the system's own pak and the other's `replace_launch` is refused. From nx-redux.
