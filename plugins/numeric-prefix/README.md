# numeric-prefix

Names starting with `1) `, `01. ` or `[1] ` sort by that number (2 before 10), and the number is left off the name shown; turn the `hide` setting off to keep it. It reads the shown name, so it works for games, folders and `map.txt` names. Numbered entries come first, then the rest in the usual order. On the root only consoles move, staying between Recently Played and Collections, and a root another plugin replaced, such as `all-games`' or `focus-mode`'s, keeps its owner's order. Recently Played and collections keep their own order. From marcelopcx and Ru_UI.
