# clear-recents

Clears Recently Played. A Clear recents tile on the quick menu (the `tile` setting, on by default) shows while there are recents, and in Recently Played **Y** (the `button` setting picks another) removes the selected game or clears them all, opening a menu of the two when both apply. Clearing asks first, then lists the folders again, so the quick menu's Recents tile goes away. Outside Recently Played the button is left to other plugins. From MyMinUI, MinUI-Zero, nx-redux and Nocturne.
