# transitions

Picks how folders push and pop and how the game switcher comes in, and owns the `transition` slot. The `style` setting picks `slide` (the default): a push slides the old list out to the left as the new one comes in from the right, a pop slides them the other way, and the game switcher slides down from the top over the game list; `fade`, the new screen fading in over the old one; `slide_fade`, the new screen fading in as it moves a quarter of the way into place, from the right for a push or the top for the game switcher, while for a pop the old list fades out as it moves a quarter of the way to the right; `stock`, stock's transitions; or `off`, none. The `speed` setting is `fast` (150 ms), `normal` (250 ms, the default) or `slow` (500 ms), and `ease` is `linear`, `in`, `out` (the default, as stock's slides) or `in_out`. Launches stay stock's, as the `launch` slot isn't this plugin's. The launcher's Menu transitions setting must be on for any of this to run: with it off there are no menu transitions, whatever the style. From radther and Nocturne.
