Third-party code in mosaic-launcher

The launcher works out RetroAchievements game hashes with code from these
projects, built into the launcher from the git submodules under vendor/ at
the commits NextUI's minarch builds. The launcher's own code stays under the
licence in LICENSE, and the plugin SDK under sdk/LICENSE.

- rcheevos (vendor/rcheevos, commit 40d916de00fe757bab40fb4db41a7912193a48e3):
  its rhash folder. MIT License.
- libchdr (vendor/libchdr, commit 47d794151b2b64f6aba60304e6480f4f5a2bc24b):
  BSD 3-Clause License. It brings with it:
  - LZMA SDK (deps/lzma-26.02): public domain.
  - miniz (deps/miniz-3.1.2): MIT License.
  - Zstandard (deps/zstd-1.5.7): BSD License (or GPLv2, at the user's
    option; the BSD License is taken here).
  - dr_flac (include/dr_libs/dr_flac.h): public domain or MIT-0.

The bundled video-previews plugin loads FFmpeg's libavutil, libavcodec and
libavformat with dlopen, never linking them. On devices they're FFmpeg
6.1.2, built by `make devices` from the release tarball at
https://ffmpeg.org/releases/ffmpeg-6.1.2.tar.xz with the options in
plugins/video-previews/ffmpeg/build.sh, unchanged, as an LGPL build (no GPL
parts). They're under the GNU Lesser General Public License, version 2.1
or later, whose text ships beside them as ffmpeg-COPYING.LGPLv2.1 in the
plugin's lib folder. They can be replaced with any build of the same
version and options.

The bundled romm plugin speaks HTTPS with BearSSL (vendor/BearSSL, its
sources copied unchanged from https://www.bearssl.org/git/BearSSL at commit
7bea48e5e850ab4cafbe68d3765cdaba13a86d6f, 2026-04-06), built into that
plugin alone. MIT License. Its licence also ships beside the plugin as
BearSSL-LICENSE.txt in its lib folder.
